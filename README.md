# 🏫 مدرسه‌یار (Madrese-yar)

سامانه مدیریت مدرسه — نسخه MVP واکنش‌گرا (Responsive Web App)

## ویژگی‌های نسخه اول

- ورود با نقش‌های **مدیر**، **معلم** و **والد**
- داشبورد جداگانه برای هر نقش
- مدیریت دانش‌آموزان (افزودن / ویرایش / حذف)
- ثبت و مشاهده حضور / غیبت / تأخیر
- ثبت و مشاهده نمرات
- ارسال و دریافت پیام و اطلاعیه
- گزارش ساده حضور و نمرات
- صفحه مدیریت دوربین‌ها (نمونه آزمایشی)
- معماری آماده برای حضور خودکار با QR و تشخیص چهره در آینده

## نصب و اجرا

### پیش‌نیاز
- Node.js نسخه ۱۸ یا بالاتر

### اجرا

```bash
cd madreseyar
node server.js
```

سپس مرورگر را باز کنید:

```
http://localhost:3000
```

هیچ وابستگی خارجی (npm install) لازم نیست — پروژه با ماژول‌های داخلی Node کار می‌کند.

## معماری حضور خودکار (آینده)

سیستم طوری طراحی شده که بعداً بتوان حضور خودکار اضافه کرد:

```
دوربین ورودی / دستگاه QR
        ↓
احراز هویت دانش‌آموز (QR یا تشخیص چهره)
        ↓
ثبت ورود + ساعت + source=qr|camera
        ↓
ثبت رویداد در attendance + audit_log
        ↓
ارسال اعلان به والد
```

- فیلد `students.qr_code` از قبل وجود دارد.
- API ثبت حضور پارامتر `source` را می‌پذیرد.
- در صورت `source=qr` یا `source=camera`، اعلان خودکار به والد ساخته می‌شود.
- تشخیص چهره **پیاده‌سازی نشده** و باید به عنوان ماژول جدا اضافه شود (با رعایت رضایت و قوانین حریم خصوصی).

## اتصال واقعی دوربین‌ها و اعلان‌ها (مرحله بعد)

### دوربین‌های واقعی
1. جایگزینی `stream_url` با آدرس HLS/RTSP واقعی
2. استفاده از پخش‌کننده وب (مثل hls.js یا WebRTC)
3. محدود کردن دسترسی بر اساس نقش و سیاست مدرسه

### اعلان واقعی
1. اتصال به سرویس SMS (کاوه، فراز SMS و ...) یا Push Notification
2. افزودن صف (queue) برای ارسال اعلان‌ها
3. تنظیمات «دریافت اعلان» برای هر والد

### تشخیص چهره
1. ماژول جداگانه که تصویر را دریافت و `student_id` برمی‌گرداند
2. فراخوانی `POST /api/attendance` با `source=camera`
3. رعایت کامل قوانین حفاظت از داده‌های شخصی دانش‌آموزان

## امنیت (MVP)

- رمز عبور با PBKDF2 + salt ذخیره می‌شود
- توکن امضاشده با HMAC (قابل ارتقا به JWT واقعی)
- کنترل دسترسی بر اساس نقش در تمام APIها
- ثبت سوابق ورود و تغییرات مهم (audit_logs)
- دسترسی دوربین فقط برای مدیر

در محیط واقعی:
- حتماً از HTTPS استفاده کنید
- کلید مخفی توکن را تغییر دهید
- به PostgreSQL یا پایگاه داده مناسب مهاجرت کنید
